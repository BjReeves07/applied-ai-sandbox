## Bug hunt #1 — SQL injection
- Bug: The SQL query uses an f-string to directly interpolate user input, allowing an attacker to inject malicious SQL through the q parameter.
- Why Claude wrote it: Claude pattern-matched on older code examples that used raw SQL strings before modern ORM practices were standard.
- Fix: Use parameterized queries — db.session.execute("SELECT id, title FROM notes WHERE title LIKE :q", {"q": f"%{q}%"}).
