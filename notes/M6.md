# M6 — Other Tools Tour

## Copilot — installed
- Observation: Copilot gives fast inline completions while typing but lacks project-level context like CLAUDE.md, making it great for boilerplate but weaker for convention-aware changes.

## Cursor (or Windsurf) — installed
- Observation: Cursor wins when you want an agent and editor in one place; Claude Code wins when you already live in the terminal and want stricter control over what runs.

## Gemini CLI (or Codex CLI) — installed
- Same prompt comparison: Claude Code gave a more accurate and structured explanation of the app; Gemini CLI was faster but less precise about the file relationships.

## Chat (Claude.ai or ChatGPT) — used for
- Observation: Pasting the M5 task 1 diff into chat caught that there was no validation preventing an empty tags list from being saved, which a junior reviewer should flag.

## Tool decision matrix
| Situation | Tool I'd reach for | Why |
| --- | --- | --- |
| Multi-file feature with good CLAUDE.md | Claude Code | Reads project conventions and enforces them across files |
| 5-line helper autocomplete while typing | GitHub Copilot | Inline completions are faster than switching to a terminal agent |
| Brainstorm three design approaches | Claude.ai chat | No code execution needed; chat is better for planning and tradeoffs |
| Review a teammate's PR for security issues | Claude.ai chat | Paste the diff and ask for risks; no file access needed |
| Cross-file refactor with consistent renames | Cursor | Composer handles multi-file diffs inline with preview |
| Learning a new library's API | Claude.ai chat | Explain and example without needing project context |
